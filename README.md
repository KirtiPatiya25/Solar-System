🚀 SOLAR SYSTEM

Explore the wonders of our Solar System with this interactive and visually appealing project made purely with HTML and CSS. This project represents the planets, their relative sizes, and positions around the Sun in a clean and educational layout.

✨ Features

All major planets displayed with unique colors and sizes.

Responsive design that works on desktops, tablets, and mobile devices.

Clean and simple HTML structure with elegant CSS styling.

Educational tool: Learn planet positions and relationships in the Solar System.

Easy to view locally or host online.

🛠 Technologies Used

HTML5 – Structure and content.

CSS3 – Styling, layout, and animations.
